# 🚀 Antigravity Assistant

Удобное нативное расширение для **Antigravity IDE**, добавляющее в нижнюю панель (Status Bar) быстрое переключение аккаунтов, мониторинг квот и статус подключения.

---

## ✨ Возможности

- 👥 **Быстрое переключение аккаунтов (Account Switcher):**
  Мгновенный переход между сохранёнными аккаунтами без ручного ввода паролей и выхода из среды.
- 📊 **Мониторинг квот и лимитов:**
  Отображение тарифного плана (`PRO`), остатка лимитов моделей в режиме высокого качества рассуждений (High) и точного времени сброса квот на русском языке.
- ⚡ **Статус сети и страна подключения:**
  Отображение страны подключения и актуального пинга в строке состояния и подсказке.

---

## 📦 Установка

### Вариант 1: Через VSIX
```powershell
& "$env:LOCALAPPDATA\Programs\Antigravity IDE\bin\antigravity-ide.cmd" --install-extension ag-toolkit-1.2.0.vsix
```
